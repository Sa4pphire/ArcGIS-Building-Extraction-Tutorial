# 项目背景

高分辨率遥感影像中的建筑物提取可以用于城市更新、土地利用调查、灾害评估和地图更新。深度学习模型需要大量影像与标签对，而GIS标注与深度学习训练之间存在数据格式和空间关系上的差异。

本教程重点解决这段“中间流程”：

- ArcGIS Pro产生的是带空间坐标的建筑物面；
- 语义分割模型需要固定尺寸的RGB影像和类别索引掩膜；
- 目标检测模型需要影像和像素坐标边界框；
- 训练与验证必须按空间位置隔离，才能减少重叠切片造成的数据泄漏。

教程代码不绑定某个盘符或单个项目。只要输入是具有空间参考的Byte型三波段GeoTIFF，以及与其坐标系一致的Polygon Shapefile，就可以复用空间预检和数据导出步骤。
